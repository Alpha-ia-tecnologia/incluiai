# Fotografias sintéticas dos temas de jogos

20 imagens criadas com o recurso integrado image_gen.imagegen, sem fotografias de pessoas reais ou dependências remotas. Imagens WebP de 640 × 640 pixels, qualidade 88, com fundo claro. Destino: public/images/games/legacy. Cada imagem possui arquivo .webp.json com prompt exato, origem e arquivo original.

Os temas de natureza e os retratos de emoções são documentados separadamente.
